최신 변경 diff를 리뷰해줘.

이의 문턱 (정본: `FILE_BASED_REVIEW_PIPELINE.md`): 종결을 막는 이의는 (가) 실사용의 잘못된 결과·데이터 손실·보안·회귀 (나) 요청·AC·spec 이탈·다음 단계를 잘못 이끄는 누락 (다) 검증이 결함을 덮지 못함뿐이다. 이의마다 `경로:` 줄에 현실에서 일어나는 경로를 적는다. 그 밖(문구·서식·유지보수성, 증거·기록 형식(`맞닿은 곳:` 제외), 실패 주입으로만 재현되는 경로, rd 가 만들지 않는 입력의 경계)은 Summary 끝 `메모:` 줄로 내며 종결을 막지 않는다.

검토 기준
- 논리 버그
- 회귀 위험
- 성능 문제
- 보안 문제
- 맞닿은 곳: PR 본문 목록을 diff 와 대조한다. 누락(`없음` 오류·발행될 본문에 없음)·사실과 다른 항목·근거 없는 「추론」·확인할 길이 있는 「확인 불가」(없으면 근거)는 `맞닿은 곳:` 발견(이의)이며 현재 PR 본문에 보완될 때까지 연다. 새 입력을 받는 기존 로직의 결함은 이번 변경의 결함이다
- 치명 결함 범주 — 「맞닿은 곳」 목록의 곳까지 읽는다
  - 데이터 안전: 삭제·덮어쓰기·부분 실패 뒤 데이터가 손실되거나 어긋나는 경로가 있는가
  - 경쟁 조건: 동시 실행·재실행·중단 후 재개에서 상태가 깨지는가
  - 신뢰 경계: 외부 입력·LLM 출력·파일 내용이 검증 없이 명령·경로·쿼리(셸 인젝션 포함)로 들어가는가
  - 열거형 완전성: 새 값·상태를 모든 소비처가 처리하는가
- CURRENT_TASK.md 정합: 커밋된 `CURRENT_TASK.md`가 HEAD 기준 현재 단계(Status·Spec·Plan·Next Step)와 일치하는가
- 변이 증거: 필수 대상 단언 결과표에 `생존`·원복 `미확인` 행이 있으면 이의. 결과표 형식 결함은 `메모:` (`rd-workflow/docs/guides/mutation-check.md`)
- spec·plan·AC 이탈: diff 가 spec·plan(`full`)·REQUEST AC(`standard`)와 어긋나는가. 경로는 `CURRENT_TASK.md` 의 `## Spec`·`## Plan` 에서 찾는다. 사유가 spec 의 「구현 중 변경」 절이나 REQUEST 에 없으면 이의
- 사용자 확인: 사용자에게 보이는 결과나 백그라운드 동작이 바뀌면 결과·진행·실패를 사용자가 볼 수 있는가. 빠졌거나 spec·AC 와 다르면 이의. 사용자에게 닿지 않는 내부 변경은 제외
- 범위 밖 변경: REQUEST·CURRENT_TASK 에 적힌 범위를 벗어난 리팩터링·포맷·파일이 있는가
- 테스트·검사 약화: 새·변경 테스트의 동어반복·구조 결합·mock 과다(정의: `core.md` 테스트 규칙)는 검증 결론이 바뀔 때만 이의. diff 가 검사를 약화한 곳 — 새 검사 끄기 주석(`@ts-ignore`·`eslint-disable`·`noqa`·`type: ignore`·`istanbul ignore`), `.skip` 추가·테스트 파일 삭제, 남은 테스트의 assertion 제거, 커버리지·성능 임계값 하향, 통과만 시키는 미구현 stub — 은 그로써 검사가 실제로 줄고 사유가 REQUEST·spec 에 없으면 이의. 같은 단언·검사를 다른 곳으로 옮긴 것은 약화가 아니다
- macOS 기본 도구: 새·변경 셸 테스트는 그 파일만 `PATH=/usr/bin:/bin:/usr/sbin:/sbin bash <파일>` 로 한 번 실행한다(BSD `sed`·bash 3.2). GNU 도구에서만 통과하면 이의. 실행할 수 없으면 Summary 에 미실행이라고 적는다
- 제거 신호: 이 변경(요청·설계·규칙)으로 쓰이지 않게 된 코드·분기·설정·문서 절, 같은 사실을 두 곳에 둔 규칙, 발동한 적 없는 만약을 위한 처리, 반복해서 지켜지지 않는 규칙(문구 강화 대신 검사·hook 으로 바꾸거나 삭제)이 있는가. 있으면 `제거:` 발견(이의)으로 낸다
- 정리 후보: diff 가 닿은 파일에 이번 변경 전부터 있던 로직 중복·크기 초과 파일·임시 코드·우회는 `메모:` 대신 `정리 후보: <경로> — <내용>` 줄로 적는다. 이번 변경이 만든 것은 `제거:` 발견으로 낸다
